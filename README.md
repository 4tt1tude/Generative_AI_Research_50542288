# Generative_AI_Research_50542288

This repository contains research materials for the project "Using Generative AI Tools - Boon or Bane."

## Project Structure

- 01_Literature_Review: journal articles, conference papers, books and newspaper articles.
- 02_Quantitative_Analysis: survey questions, raw data, analysis scripts and analysis reports.
- 03_Qualitative_Analysis: interview protocols, interview transcripts, consent forms and analysis reports.
- 04_Drafts_and_Reports: research proposals, conference papers and final reports.
- 05_Additional_Materials: information sheets, photos and other media files.

## Navigation

Each folder contains a README file that explains the type of data stored in that folder.

## Collaboration

Collaborators should use clear file names, write meaningful commit messages, and pull the latest version before making changes. Sensitive research data should only be accessed by authorised team members.
